# 表格多选样式

2026-09-20，按页面批注与参考图统一。

- 复选框与表头保持同列；部分选中显示半选，选中行读取浅主题色。
- 选择数量大于零时，在表格上方显示独立的浅灰批量操作条。
- “已选择 X 项”使用 400 常规字重，不使用 strong 或加粗。
- 批量操作使用正式 DS 文字按钮，默认背景、边框透明，文字读取当前项目主题色；取消选择位于右侧。
- 普通多选、跨页选择、资源管理、业务流程、多级表头示例复用 TableSelectionBar，避免各自实现不同外观。
- 跨页选择保留，并显示其他页的已选数量；页脚只保留分页，不重复堆放选择计数。
- 原有业务确认、失败反馈和只读限制保留；示例批量启用/停用实际更新示例行状态。

实测普通预览与资源管理批量条均为 400 字重；按钮为 ghost，背景/边框透明，公共基线文字为 rgb(49,92,82)。资源表头半选正确；跨页选择两项后返回第一页，原行仍勾选，显示“已选择 2 项（含其他页 1 项）”。

相关四个测试文件共 35 项通过；主站构建通过。

## 行内文字操作

行内文字按钮默认、悬停和按下均不绘制底色或边框；悬停时无外框/阴影，键盘 focus-visible 继续保留焦点提示。普通操作使用项目主题色；删除使用 `variant="tertiary" semantic="danger"`，读取危险文字 Token。危险文字组合已进入 Button 契约和配方，不再回退为普通主题色。

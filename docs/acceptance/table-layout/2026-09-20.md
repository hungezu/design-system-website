# 表格布局、选择与设计 Markdown 验收

范围：共享 DSTable / DSPagination、ResourceWorkflow 列表模板、公共与项目模板、交互模式和新快照的 DESIGN.md。历史冻结发布不重写。

## 修复与浏览器证据

| 问题 | 修复 | 实测 |
|---|---|---|
| 表格勾选图形偏上 | 16px 框体内居中放置 12px Check 图形，去除旧 left/top 和旋转边框；半选横线同中心 | 原中心偏移 X -0.713px / Y -2.201px；修复后两轴绝对偏差均 < 0.01px |
| 表头与内容列错位 | 表头与数据单元格共用列宽及伸缩规则 | 所有对应列的左边界差 0px |
| 分页在左侧 | 总数左侧，页码/翻页/每页条数组右侧 | 分页组与表格可视容器右侧差 < 0.01px |
| 批量操作混在新增旁 | 新增在普通工具栏右侧；有选择时显示独立批量条 | 浏览器确认区域分离；当前页 3 项，全筛选结果 4 项 |
| 全选范围不清楚 | 表头“全选当前页”；跨页全选使用显式“选择全部 N 项” | 部分选中显示半选；翻页显示其他页数量；查询变化清空选择并回第一页 |
| 窄屏固定列无效 | 以 DSTable 作为唯一表格滚动容器；内部表头与行设最小宽度 | CSS 视口 390px，根 scrollWidth 390px；表格内容宽 720px；横滚 309.52px 后首列与操作列仍固定 |
| 行操作占用过宽 | 使用“查看”“编辑”短标签，保留完整无障碍名称；操作列 140px | 390px 视口下两项操作与选择列可见，分页靠右 |
| 无批量任务仍能产生隐藏选择 | 不可选择时 guard，非批量/只读不显示选择列 | 只读无复选框，新增和编辑禁用；空数据不显示分页 |

独立 DSCheckbox 的勾及半选横线、DSRadio 的 6px 圆点、DSSwitch 圆钮已检查：未发现相同偏移。表格修复通过共享 Runtime 生效；公共资源与项目主题继续从所在 PreviewScope 获取颜色。

## 规则交付

- `src/data/patterns/table-layout.ts` 是列表布局/选择规则来源，模板与模式共用。
- 新快照将合同写入 `patterns.json.tableLayout`；生成的 DESIGN.md 读取冻结合同。
- 文档明确普通工具栏、批量操作条、当前页选择、跨页选择、筛选重置、加载/空数据/只读/部分失败、窄屏和表单动作顺序。
- 缺少该合同的旧快照明确提示规则未冻结，不套用最新规则宣称旧包已实现。
- 根 DESIGN.md 同步；新项目包中的最小示例隐藏空结果分页、分离筛选与主操作，使用真实批准组件。

# 最终复核与修复

日期：2026-09-19。此记录替代上一轮 `ACCEPTANCE.md` 的完成结论。

## 结论与范围

上一轮确有遗漏，已修复本轮发现的实现与集成错误。R01–R20 在本地稳定候选范围内关闭；这不代表 88 个组件的任意组合均已认证，也不代表 Figma、远端部署、SSO 或真实 AI 服务已经接通。

当前可交付范围：88 个组件详情、316 个明确示例、核心 20 项 API/状态/Storybook/测试映射、12 个模式的 33 个可执行场景、三类模板、Node/SQLite 工作区与项目备份恢复、冻结资产对比、独立组件消费包。具体候选版本、运行时标识及 SHA-256 以相邻 `verification.json` 和 `artifacts/local-stable/delivery.json` 为准。

## 本轮发现及修复

|遗漏或错误|本轮修复与验证|
|---|---|
|状态表展示配方或通用色块，不能证明组件真正取值|新增 `LiveStyleInspector` 与 DOM 实测；区分主示例和画廊，读取当前状态、颜色、字体、尺寸和继承变量；关闭浮层时清除实测。Button 保留明确标为配方参考的表格。|
|版本切换中 URL 与上下文短暂不一致，损坏 CSS 可能回落到草稿|按请求版本隔离加载、错误及结果；解析前校验项目和版本；拒绝空 CSS、HTML 与上下文错配。新增版本竞争和冻结上下文回归。|
|PreviewScope 只传变量，独立控件字体未实际继承|作用域实际应用字体、字号与文字颜色，Portal 继承所属作用域。独立消费字段实测 Georgia / 18px。|
|构建时旧 Runtime 覆盖正式按钮边框、行高和尺寸|兼容按钮 CSS 显式排除 `.gkx-button`，保留旧 Runtime 控件规则。构建后主按钮背景、边框均为恢复后的 #6236FF，行高 22px；增加导入顺序隔离回归。|
|加载示例只设 disabled，后来补上 spinner 仍改变宽度|使用真正 loading；居中加载环不参与布局，保留原文本/图标槽和可访问名称。主站切换前后均为 62×32，Storybook 约 61.6×32。Dialog/Drawer 有实际加载及关闭保护。|
|高级筛选取消仍生效、初始长文本假脏、重复提交和卸载后完成|筛选先暂存后应用；统一初值；同步提交锁与卸载保护；取消不改变已应用条件。|
|批量操作缺少确认和部分失败反馈；删除恢复丢失位置|正式 DS 确认、取消、加载、部分失败保留；删除撤销恢复原位置并切回可见页，说明筛选外记录。浏览器确认四项归档后保留一项依赖失败。|
|模式场景与说明混淆，模板状态不完整|12 个模式提供 33 个真实场景，URL 和复制代码包含场景参数；加载、超时、错误、校验、只读、长内容、新建/编辑等有对应流程。说明导航不再伪造删除输入或撤销操作。|
|未保存编辑可被页面/项目/版本切换丢失|链接、项目/版本切换、模板变体、浏览器遍历和离开页面接入保护。回归验证取消及历史位置恢复；浏览器原生确认弹窗无法由本次工具可靠接管，未将该路径写成浏览器通过。|
|差异遗漏模板；快照记录损坏被默认为空|差异覆盖全部集合及布局/区域外观；不可读项明确报告；损坏存储明确失败。校验快照资产字节数、内容标识、Token CSS/JSON、组件清单和项目关联。|
|迁移到服务端后，备份仍读取旧 localStorage|新增服务端导出、恢复预检和事务恢复；携带项目配置、已保存主题和完整快照，支持动态项目迁移。权限、20 MB 限额、冻结标识、同号内容、预检后修订均校验；回滚包括审计写入。旧浏览器原始记录单独保留。|
|服务端主题校验允许零字号或外部资源样式|复用备份主题校验，拒绝零字号/控件高度与外部资源请求，服务端专项回归通过。|
|旧代码和旧快照一起缓存时会误报一致；候选同名难以区分|源码指纹进入候选版本，比较宿主目标/代码/快照三方；校验源码、tarball SHA、编译代码和独立安装。冷启动前页面正确拒绝旧包，重装重启后接受新候选。|
|新登录测试含不支持的 TypeScript 参数|修正查询参数，完整类型检查与构建通过；保留同工作区已接入的真实登录、权限和账号管理实现。|

此前错误+hover、OTP 格位、Toast 重开、Avatar 换图、Tag 移除、选中+禁用、占位对比度、重复示例和静态组件状态声明的修复继续保留；回归包含在完整测试与核心证据映射中。原审计和修复前清单保留以便追溯。

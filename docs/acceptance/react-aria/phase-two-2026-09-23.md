`ToggleButton`、`ToggleButtonGroup`、`Autocomplete`、`Slider`、`TagGroup`、`Meter`、`Calendar`、`DateField`、`DateRangePicker`、`RangeCalendar`、`TimeField`、`ColorArea`、`ColorField`、`ColorPicker`、`ColorSlider`、`ColorSwatch`、`ColorSwatchPicker`、`Breadcrumbs`、`Disclosure`、`DisclosureGroup`、`Link`、`Toolbar`、`Separator`。

本批仅进入国科信当前草稿，没有改写历史冻结版本，也没有发布新版本。

## 闭环结果

- 国科信项目批准组件：69 项（55 个通用组件 + 14 个 AI 组件）。
- React Aria 家族项目覆盖：47 / 54，公共网站已有的家族已全部准入。
- Runtime Registry：70 项，比项目草稿多一个内部 `icon`。
- 第二批 23 项已纳入 Registry、ComponentAsset、React Binding、Token / 状态契约、Storybook 和工作区迁移。
- 项目现在只剩与公共网站相同的 7 个基础缺口。

## 同步修复

- Breadcrumbs 当前页改为带 `aria-current="page"` 的非链接文本。
- ToggleButton / ToggleButtonGroup、Slider、Link、Disclosure 和颜色控件补齐禁用态表达。
- ToggleButtonGroup 的预览补充可访问组名称。
- ProgressBar 将不确定进度从泛化 `loading` 状态拆为 `indeterminate`，不输出伪百分比，并支持减少动效。
- 项目 ComponentAsset 中的数字、日期、集合与回调类型改为准确类型，不再用字符串或 ReactNode 泛化表达。
- ColorPicker 和 ColorSwatchPicker 的 `isDisabled` 改为自有组合契约，并向颜色区域、滑块、输入框和色块项传递，避免只有外层样式而子控件仍可操作。
- 核心验收映射生成器补全两批基础组件，并在缺失回归入口时直接失败，不再生成 `src/design-system/undefined`。

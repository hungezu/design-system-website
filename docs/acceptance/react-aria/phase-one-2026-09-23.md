## 浏览器证据

- 国科信草稿组件目录实际渲染 46 项，本批 12 项全部可达。
- `/components` 与项目组件页均没有组件数量统计区块。
- 已验证 SearchField 清空、NumberField 步进、ComboBox 键盘选择、ListBox 选择、Tree 展开、DatePicker / Popover / Tooltip Portal 主题继承。
- CheckboxGroup 加载状态会锁定选项并在包装层暴露 `aria-busy`。
- ProgressBar 不确定状态不输出 `aria-valuenow`，并使用独立动效；减少动效模式停止动画。
- DropZone 提供可访问名称，禁用变体会同时禁用文件选择按钮。
- 最终页面控制台无 error。

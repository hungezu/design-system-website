# 全站表格操作规则修订

本次按用户截图修正真实前端，保留灰色外框、白色内容区与可配置 radius-table。

## 统一规则

1. 表格上方普通操作靠左，从左到右按重要性和使用频率递减排列。
2. 不显示常驻的“表头全选仅作用于当前页”；复选框无障碍名称继续明确“全选当前页”，选择范围和半选逻辑保留。
3. 分页左侧只显示总条数，删除冗余当前页/总页数；页码与容量选择仍在右侧。
4. 行内文字按钮 margin、左右 padding 与左右透明边框为 0，文字起点对齐“操作”表头；组内间距由 gap 控制。
5. 操作列按实际内容测量宽度，表头与各行同步；最后一个操作后仅保留 16px，不保留旧的 140px/260px 空列宽。
6. 批量操作条背景为中性 surface-secondary，浅色模式 #F7F8FA，不使用 brand-secondary。
7. 固定操作列通过 shadow-table-fixed 的单侧轻阴影和 z-index 区分层级；固定表头高于数据行固定列。

## 实际覆盖

- 共享 DSTable、DSPagination、行内 DSButton；自动列宽 hook 支持内容/字体尺寸变化并抑制无效重渲染。
- 公共/项目组件页及其变体、资源管理示例、列表模板、批量模式、主题预览。
- 原生成员/邀请/用户管理表格：行内按钮对齐、固定操作列、16px 单元格边距及轻阴影。
- 组件页“使用方法”、模式/模板规则、根 DESIGN.md、冻结合同与新交付包生成的 DESIGN.md。
- 历史已发布包不重写。

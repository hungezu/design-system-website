# AI 组件库验收

日期：2026-09-21
参考：HeroUI Pro 公开 AI 组件文档及公开示例，入口 https://heroui.pro/docs/react/components/chain-of-thought 。采用现有 React Aria / Runtime 独立实现，没有引入 Pro 包或绑定模型 SDK。

## 交付范围

14 类组件：执行过程、聊天附件、对话容器、会话列表、聊天加载、聊天消息、消息操作、引用来源、工具调用、代码块、Markdown 内容、提示输入、建议问题、生成状态文字。

- 公共目录增加「AI 交互」分组；现有项目草稿与新项目纳入该组件族，历史发布清单与内容保持冻结。
- 每类都有真实 Runtime 导出、组件资产、明确状态、交互预览及 Storybook 源文件；Figma 未绑定，未宣称同步。
- 主题使用既有语义变量和 AI 用途变量。代码语法文字在深浅背景上修正到可读对比度；字体跟随项目配置。
- 输入支持空值禁用、Enter/Shift+Enter、中文输入组合保护、重复提交防护、发送失败保留内容、停止回调及本地附件选择/移除。
- 会话在接近底部时跟随新增消息，查看历史时保留滚动位置；可回到最新消息。
- 工具确认必须由显式点击触发，等待期间禁止重复确认，失败可重试。
- Markdown 跳过原始 HTML 和不安全链接；代码只显示不执行。复制反馈以剪贴板真实结果为准。本地预览对象 URL 在移除或卸载时释放。
- 示例响应明确标为本地模拟；正式组件不自行请求模型、上传文件或执行工具。富文本 @mentions、提示队列等 Pro 高级功能不在本次基础接口中。

## 浏览器证据

- 真实项目 `/projects/dv/components/chat-conversation?version=draft&variant=full-chat` 可见全部 14 个 AI 入口及完整聊天示例，读取项目字体 PingFang SC 和项目品牌变量。
- 修复基础文本域的 96px 最小高度覆盖后，空输入实测约 36px；完整聊天改为宽预览，配置区位于下方。
- 深色、360px 容器实测内容 scrollWidth=clientWidth=360，输入区宽约 328px，无横向页面溢出。
- 长代码内容宽 2269px，代码视口宽约 326px，只在代码块内部滚动。
- 发送后可停止模拟生成，已生成内容保留并显示「已停止生成」。图标缺失计数为 0。
- 减少动画媒体规则关闭状态文字、圆点与旋转动画；组件样式包含清晰的键盘焦点。

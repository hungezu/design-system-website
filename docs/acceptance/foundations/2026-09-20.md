# 设计基础完整性与浏览方式

## 结果

公共设计基础与项目设计规范共用同一实现，仅保留“设计变量 / 图标”。默认完整展示全部已注册基础变量，不再有“全部”混排或无效排序。

当前基础层 144 项：原有 66 项语义/字体/尺寸等变量，加 78 项实际色阶变量。原页面漏掉的 8 项动效已经显示。色阶为品牌、成功、警告、错误、信息色各 10 阶，中性色与品牌倾向灰各 14 阶，使用历史规范记录的 tvision-color 1.6.0 HCT 引擎。主色所在级数由引擎决定并标记“基准”，不强制固定第六级。

色阶进入 semanticTokens、生成 CSS、项目主题解析和后续冻结快照，不是仅绘制的装饰色块。已有品牌 Hover / Active / Subtle 和状态语义值保持配置，不自动改成某个色阶编号。组件专属 35 项 Button Recipe 和 Runtime 兼容别名保留原职责，不作为基础变量重复陈列；144 是基础层完整性，不宣称所有未来组件需求都已建模。

## 页面调整

- 变量列表呈现名称、ID、值、用途、项目来源和可展开的组件引用；可复制变量。
- 普通变量不再进入重复内页；旧链接跳回列表对应锚点，保留项目与版本。
- 图标详情仍提供线性/面性预览，有实际增量信息，因此保留。
- 搜索支持名称、ID、用途、分组和当前值，结果保持变量表或图标网格，不再切成丢失值信息的卡片。
- 增加分组定位，缩减搜索区高度，移除无效排序；颜色与普通变量在窄屏重新排布。
- 清除搜索保留分类、项目、版本。历史页读取冻结 CSS、JSON 色盘及对应 Icon Pack；失败不会回退当前项目草稿。
- 旧色盘只有 JSON 值、没有 CSS 声明的色阶，复制实际色值，不创建不存在的 var() 引用。旧规范的兼容补充值有来源标记。

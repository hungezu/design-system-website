# AI 设计 Markdown 回流验收

日期：2026-09-21。

## 结论

项目“版本记录”已增加“导入 AI 修改稿”。编辑者和项目管理员可上传 `.md` 或粘贴 Markdown，检查结构化差异和真实组件预览后，将选中的白名单主题参数写入当前草稿。冻结版本不变，也不会自动发布。

## 关键保护

- 只接受 `design-workspace/design-md-1` 项目交付规范，同时校验项目短 ID、发布 ID、来源版本和快照。
- 通过“来源冻结版本 → AI 修改稿 → 当前草稿”三方对比，排除 AI 未改的旧值。
- 当前草稿也修改了同一字段时，归入“需逐项确认”，默认不勾选；“全选可直接应用项”不会选中它们。
- 服务端在应用时重新解析原 Markdown，仅接受变更 ID，并经过完整主题校验与 revision 乐观锁。
- 组件、Pattern、布局正文、代码片段和无法反向映射的 Token 仅作参考，不会被猜测写入。
- 文件限制为 200 KB，拒绝异常控制字符、过长单行、重复身份字段、重复 Token 和越界值。导入原文仅作转义文本显示，不执行 HTML 或代码。

## 验证证据

- `npm test`：68 个测试文件、921 项测试通过。
- `npm run test:access`：34 项服务端测试通过，包含回流成功、修订冲突和冻结版本不变。
- `npm run typecheck` 与 `npm run typecheck:server` 通过。
- `npm run build` 通过；仅保留既有历史发布差异和 chunk 体积警告。
- `npm run verify:design-md` 通过；两项目三个验收版本的身份、API、Token 与独立编译仍然有效。
- `npm run lint` 无 error；保留 10 条既有 Fast Refresh warning。
- 隔离工作区中的真实浏览器验收：完成粘贴、解析、三方差异、默认勾选、需确认项默认不选、批量选择不跨越确认项、候选主题预览和弹窗滚动检查；浏览器控制台无错误。
- 当前浏览器工具不支持设备视口切换；窄屏收敛已在 CSS 和组件结构中落地，本次未声称完成真机移动端视觉验收。

## 本期边界

本期不持久保存多份原始 Markdown，也不自动反向改写组件、Pattern 或页面结构。如需要跨刷新的“AI 修改稿库”，应作为下一阶段增加不可变文档记录与备份契约。
